# Robux Limit Tracker site

Public product, privacy, and support pages for the Robux Limit Tracker browser extension.

## Pages

- `/` — product overview
- `/privacy` — extension privacy policy
- `/support` — installation and troubleshooting help

## Local development

```powershell
npm.cmd ci
npm.cmd run dev
```

## Validation

```powershell
npm.cmd test
npm.cmd run lint
```
