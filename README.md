# Robux Limit Tracker site

Public product, privacy, and support pages for the Robux Limit Tracker browser extension.

Public site: <https://woahitsjeebus.github.io/RTLT/>

## Pages

- `/RTLT/` — product overview
- `/RTLT/privacy/` — extension privacy policy
- `/RTLT/support/` — installation and troubleshooting help

## Local development

```powershell
npm.cmd ci
npm.cmd run dev
```

## Validation

```powershell
npm.cmd test
npm.cmd run lint
```

Every push to `main` publishes the static output through GitHub Pages. The
public site does not have a sign-in system and does not collect visitor data.
